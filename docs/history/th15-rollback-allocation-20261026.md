# TH15 多人回滚：复用快照容器

多人回滚快照直接复制到保留容量的字段和 ECL 子线程容器，供 13 槽快照环重复使用。动画恢复通过预先定容的连续地址映射重建 VM 引用，省去每个映射项的独立节点分配。动画图没有嵌套面板时，捕获直接保留遍历顺序，省去地址排序。

改动位于 `ports/th15-mp`，维持 12 帧纠正窗口、游戏状态字段、动画层顺序、VM 身份及随机数状态。全部 10 项原生回滚检查通过；一面与 Extra、两人与三人四组场景，每组 480 帧、最高 2000 发弹幕、约 12000 个动画节点，全部通过精确状态与重演校验。

首轮本机 Release 对比，四组场景的平均捕获耗时从 4.60–4.97 ms 降到 4.21–4.49 ms，平均恢复耗时从 5.54–7.54 ms 降到 4.00–5.52 ms。性能样本与前后运行器保存在 `artifacts/th15-optimize-20261026/`，用于后续相同场景的交错测量。
