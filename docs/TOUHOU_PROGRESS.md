## [th14] 東方輝針城 v1.00b

### th14 Web 适配

[AdingApkgg/thp](https://github.com/AdingApkgg/thp) 持续推进独立 C++ / Wasm 实现，保持进行中。

- 已修正普通命中中断、对话／HUD顺序、跨关卡动画回收、满火力辅助特效重建，以及有原作写入证据的激光栈残留与独立进程cookie。
- 关卡加载现在分别等待60ms下限和实际主机任务完成，Web采用异步计时器；未把某次原作调度延迟写成固定常量，也未调整随机数或动画序号来对齐。
- 两个独立原作进程的14370回调前缀，在声明兼容环境和各自观测的主机事件下，所选32字全部逐字节一致；第二份直接捕获Sleep返回，未使用种子存储代理。默认主机负对照保留视觉随机数分歧；不宣称默认Web调度与原作等价。
- 魔理沙A Easy在已观测启动环境与回调时间间隔下，34783个原作回调所选32字仍全部相同，无原作尾部缺失。独立前缀140411次动画分配的句柄、文件、脚本全部一致；既有独立178条回收记录含计时匹配。
- 30种自机／难度共2763367回调与cb0f291核心逐字节一致，各自自然结束并稳定90帧；这属于回归，不是全模式原作验收。
- 当前构建完成灵梦B Normal六关生产Launcher／WebGL回放，自然进入再生终了，得分801525760、Graze17551，回放开始后无警告／错误，本机静音。
- 原作灵梦B另一次bootstrap全程采集在第五关93104回调后访问异常，失败记录保留，未计作六面原作通过。独立冷启动、普通初始化及全模式原作音画、存档验收仍未完成，整作1:1未完成。
