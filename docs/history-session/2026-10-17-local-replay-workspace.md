# Cross-title local Replay workspace

Work stays in the existing Launcher checkout
`worktrees/launcher-th09-spectator-main` and each title's existing source owner.
No new worktrees, commits, pushes or deployment were requested or performed.
Concurrent spectator, font and monorepo work is retained.

## Behavior

- Non-TH09 file selection expands native metadata and real recorded stage
  starts. It does not start playback. Selecting a native stage starts playback
  in the permanent viewer iframe. TH09 retains its VS/round behavior.
- Native decoders supply score units, loadout, rank, date, slowdown and special
  modes. TH08 Spell Practice also exposes CP932 spell names and spell scores.
  Unrecorded stages are not playable. Missing MP per-stage scores remain unknown.
- Summary values occupy two aligned columns: name/loadout, then date/rank.
  Filename/size have their own row. Repeated NAME/DATE/PLAYER/RANK labels were
  removed. Stage/Last Score headings remain for the stage selection table.
  This fixes the old `small` selector overriding the summary layout and joining
  the values together.
- Shared browser pacing supports pause, restart, native backward reconstruction,
  0.5/1/2/4/8 rates and bounded full-speed work. Native adapters own actual game
  ticks, Replay inputs, stage bootstrap and EOF. Native loading must finish
  before a paused seek to zero can retire its target.
- TH08 ordinary has no declared total tick count. It displays unknown duration
  and disables arbitrary seek positions. Stage starts, pause, rate and restart
  still use the real native Replay path.
- TH06/TH07 pass absolute preference paths to native file reads. TH08 ordinary
  updates its boot-time resource cache from current FS bytes when opening a
  newly imported/overwritten file. TH10 MP preserves the chosen stage's native
  global input offset, clears the retired tape before reconstruction, and
  accepts the workspace's one folder level in native Replay paths.
- TH06/TH07 stop at the native recorded-input boundary. A partial recording
  need not clear its gameplay stage, so waiting for menu teardown alone kept
  consuming ticks past EOF. Fresh production viewers now stop at the recorded
  total and retain the final cursor.
- Read-only IDBFS listing/downloads remain independent of runtime preparation.
  The matching native Runtime remains the sole writer. Ordinary/MP namespaces,
  TH10 language roots, shared `.rpy`/`.rpyx` slots and TH15 MP prefixes follow
  the actual native storage contracts.

The common source is `eagler-common/browser/local-replay*.mjs` and native
descriptor helper `include/eagler/replay/Workspace.hpp`. Carrier blocks are
generated by `tools/sync-local-replay.mjs`; `--check` verifies all eight carriers.
Use zero-filled C-string buffers in HTML carriers to avoid minifier NUL bytes.

The later-stage TH10 corpus is a real keyboard-driven 2P run through Stage 1
and into Stage 2, recorded by the existing read-only-position robot. Its native

length instead of reusing the short 500-frame corpus's fixed deadline.

## Evidence boundaries

- TH08 Spell Practice/branch input is explicitly a native format corpus. A
  naturally recorded Spell Practice performance was not available in this run.
- Later-stage MP offsets have bridge unit coverage and a real two-stage TH10
  production-player check. TH11/TH15 MP codec corpora remain single-stage.
- TH09's established player is retained. This session's mounted regressions
  cover its viewer ownership and UI, not a new retail/MP gameplay golden run.
- TH20 is a hidden test product and has no new native local-player adapter in
  this change. It is not included in these acceptance claims.

This shared loading/storage/presentation experience belongs in the common
playbook; the precise per-build PASS and remaining gaps stay in this record.
