# 东方绀珠传 C++ 网页版

本地日文 1.00b 的游戏逻辑已恢复为具名 C++ 管理器及回调，网页运行不依赖原版 x86 执行器。沿用永夜抄、风神录、花映塚和地灵殿最终版的共用 SDL3/WebGL2 渲染器与网页启动器，支持连续触控、浏览器本地存档、原版录像、触控录像和章节续玩。

双击“启动绀珠传网页版.cmd”，打开 http://127.0.0.1:3007/，保持窗口开启。网站公开的文件以 artifacts/sdl-release/site/manifest.json 为准；玩家导入的文件保存在各自浏览器。

构建：使用项目中的 Node/Python/Emscripten 环境执行 scripts/build-sdl-application.mjs --release，再执行 scripts/package-release.mjs。核心对照使用 scripts/cpp/build.mjs 与 scripts/cpp/test-suite.mjs。

本次验收：319 项冻结回归通过，三个原版演示的独立世界对照合计 20228 帧；普通六面及 Extra 结算/录像、全部六面冷启动章节续玩、四机体练习与最终桌面/手机模拟启动器通过。具体范围、哈希和原版对照边界见 [整局状态与实际网页验收](docs/整局状态与实际网页验收.md) 和 reference/release-acceptance.json。

手机测试使用模拟触屏，实际设备的驱动与帧率还需公网真机复测。completeGame 表示整款实现已连接并通过发布验收，不能据此宣称所有输入序列已经逐帧证明零差异或绝无 bug。原版资源和权利归上海爱丽丝幻乐团/ZUN；启动器与共享组件授权见发布站点的授权文件。

原版录像失同步修复（2026-10-03）：修正自机子弹裁剪、短促震动随机数流、ECL 即时主要道具掉落及负残机 HUD。用户提供的六面录像已通过原版 146865 帧关键状态对照、实际网页完整回放和 322 项冻结回归，详见 [原版录像失同步修复](docs/原版录像失同步修复.md)。
