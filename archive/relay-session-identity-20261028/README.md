# 多入口会话匹配

th08、th10、th11、th12、th15 按作品、房间和局次计算原生会话 ID。同一 Relay 的域名、端口和代理路径分别负责连接选路，玩家与旁观者共用房间身份。

th08 使用主站已发布的同一份 WASM 和游戏数据，在本地 Relay 上执行双人标题预加载与开局。两个入口分别使用 `127.0.0.1` 和 `localhost`，代理路径也不同。

| 场景 | 结果 |
| --- | --- |
| 原版脚本，两人使用相同入口 | 开局成功，34 个共同逻辑帧的世界状态一致 |
| 原版脚本，两人使用不同入口 | 90 秒内均停在标题，第 0 帧未开始，页面没有报错 |
| 修正脚本，不同入口，回滚模式 | 开局成功，40 个共同逻辑帧的世界状态一致 |
| 修正脚本，不同入口，纯延迟模式 | 开局成功，101 个共同逻辑帧的世界状态一致 |

五作的实际准入函数通过相同检查：入口不同的玩家与旁观者得到同一会话 ID，换房间或换局次得到不同 ID。结果和源码摘要见[检查记录](results.json)。架构与运行入口见[联机文档](../../docs/architecture/netplay.md)和[测试入口](../../launcher/tests/README.md)。
