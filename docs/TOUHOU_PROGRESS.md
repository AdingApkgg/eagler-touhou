## [th14] 東方輝針城 v1.00b

### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植继续。[源码与复核工具](https://github.com/AdingApkgg/thp/commit/1d9999a47ea1c8510d4983d47ff22c50a544fad6)；[剩余验收](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。只推进 TH14，不新增其他作品占位，整作 1:1 未完成。

最新[普通回放首关的种子恢复](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/TH14_INITIAL_REPLAY_RESTORE_OCT27.md)：普通回放此前误用首次演示参数，脚本／动画 RNG 沿用标题页状态。按原版 `435ed0 → 435f32 → 456050` 的位 2 分支修正调用，首次普通回放也恢复两组种子，只清零玩法 RNG 计数，保留脚本调用计数。六个原始关卡头及声明的初态组合共 288 组实际指令控制，与直接编译的 C++ 恢复函数核对四个 RNG 字和 22 个映射状态字，旧参数为 0／288，相应修正参数为 288／288 相同。这个组件绑定 GameSession 调用源码，但没有把整个 GameSession 当作已与原版对照；[范围报告](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/th14-initial-replay-restore-verified-oct27.json)明确区分。

两份核心源重新编译、139 个对象经校验复用后，真实 C++ Application 经普通归一化菜单键播放同一已有 KMK 魔理沙 B Normal 输入。完整测试仍失败：27,251 个 Application 帧、8,434 行日志中，二面残机耗尽，等待三面入口失败；此前 20 项断言通过，三至六面和最终得分尚未验收。录像保存元数据标为通关并非原版实际播放证明。没有继续下载新录像，也未用生命／血量／关卡覆盖延长运行。旧暖启动提前结束未被唯一归因。

当前实际 Application 的演示回归完成 2,264 帧、七项断言，131 行日志与两幅完整画面保持一致，最后一幅 1,228,800 字节继续匹配既有独立 D3D9 对照；实际静音 sink 的 1,508,352 帧累计哈希也与绑定的旧核心前缀控制一致。此前[四边形修复](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_PROCESS_INPUT_QUAD_OCT27.md)的 192 个 C++ 语义批次／七次清除、199 份完整缓冲哈希与 D3D9 相同，两后端各 17,545 帧的日志／七幅画面／静音 PCM 一致，保留其冻结版本范围。独立 HAL 使用被观察的初始 GPU 颜色，不是原版普通 Application 整帧捕获。

[模式清单](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/TH14_MODE_ACCEPTANCE_OCT25.md)仍为 30 组自然结束记录、25 组观察到全部目标关卡入口；魔理沙 A Easy／Normal／Hard、魔理沙 B Normal／Lunatic 五组缺后续入口。自然结束、全部入口、通关与完整等价分别判断。历史相机、[effect149 栈来源](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/TH14_FOCUSED_HIT_STACK_PRODUCER_OCT26.md)、原版普通入口、完整图像／音频及浏览器持久化／输入继续验收。Stage 三面 1199 帧 `(144,373)` B=119／120 的严格失败保留，所有比较不设像素容差或 alpha 排除；其余范围见剩余清单。

静音 8218 候选此时仍固定在此前 `6ac6115`：146 个 C++ 单元全编译，133 条路由／21 项 HTTP 检查及服务的 Wasm／宿主／着色器哈希已核对，普通浏览器尚未验收，不自动继承本次玩法修复。[存储约束](https://github.com/AdingApkgg/thp/blob/1d9999a47ea1c8510d4983d47ff22c50a544fad6/docs/porting/TH14_STORAGE_POLICY_OCT25.md)继续保留 100 GiB 空闲保护及 128 MiB 新测试输出上限；旧工作输入的无损归档、恢复工具和全部观察／失败报告保留。源码发布不含原版资产、录像、归档备份、原始像素／PCM 或二进制。测试与预览保持静音，完整目标继续。
