# 原版 FPS 显示修复（WEB 1.0.3）

游戏右下角恢复原版 FPS，普通游玩、录像及暂停菜单均使用同一个显示回调。保留标题与结局不显示的原版规则。

原版 433500 注册 draw priority 72；4336e0 使用 (588,470,0)、%2.1ffps，并在格式化前加 0.05。低于 30 的颜色为 0xff5050ff，低于 40 为 0xffa0a0ff，其余白色。40c800 在排队后覆盖字体为 1，小字来自原版 ascii.anm；没有额外阴影。原版函数实执行 40 个场景/帧率样本完成位置、格式、阈值及标题/结局排除对照。

仅编译修改 cpp/sdl/BrowserRuntime.cpp：注册具名 draw_frame_rate 回调，用现有 AsciiText 与共用 SDL3/WebGL2 绘制。浏览器按完成提交的 RAF 次数测量显示帧率，单次 RAF 内的补帧不重复计数。原有逻辑帧率与录像记录时钟保留。停止、隐藏、重新启动时重置显示采样窗口。游戏逻辑、数值兼容、随机数、资源和共享渲染器源码哈希均与上一轮相同。

桌面 1280×960 与模拟手机 640×480 均完成实际 Legacy 进入、游玩、暂停和回标题检查。测试主动将 RAF 回调延后，造成多次逻辑补帧；直接从真实 GPU 上传的字体纹理坐标解析显示数字，读到 4.2fps / 13.5fps，与实际画面提交统计一致，低于对应的逻辑帧率。此人为慢速测试与软件 GPU 不代表玩家电脑或真机性能。已有 ASCII 六类字体及队列/绘图回归全部通过。

网页诊断信息上移，避免遮挡原版 FPS。另修复手机横屏长日志正文覆盖页脚“关闭”按钮的问题，保留顶栏关闭入口。
