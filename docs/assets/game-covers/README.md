# 游戏封面

用于文档进度表的官方游戏封面，来自 THBWiki，共 33 作。

- Windows 正作：`th06`–`th20`。
- PC-98 旧作：`th01`–`th05`。
- 小数点作：文件名省略小数点，例如 `th075.jpg` 对应 th075。

图片保留来源文件的原始格式和尺寸。`sources.json` 记录每张图片的来源页面、下载地址、尺寸、文件大小与 SHA-256。

封面属于对应游戏的素材，不因保存在本仓库而改用本仓库的代码许可证。

在 Markdown 表格中可用 `<img src="docs/assets/game-covers/th06.png" width="96" alt="東方紅魔郷">` 控制显示大小，图片列表头留空。
