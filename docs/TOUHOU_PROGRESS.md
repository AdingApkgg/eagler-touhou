### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植继续。[当前源码与复核工具](https://github.com/AdingApkgg/thp/commit/b743b0f360c275c33b84b82956c8dddb911c43eb)；[剩余验收清单](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。仅推进 TH14，不新增其他作品占位，整作 1:1 尚未完成。

[模式清单](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_MODE_ACCEPTANCE_OCT25.md)仍为 30 组原版自然结束记录、25 组观察到全部目标关卡入口。自然结束、全部入口与通关分别判断；魔理沙 A Easy／Normal／Hard、魔理沙 B Normal／Lunatic 五组仍缺后续入口。历史相机及 effect149 差异继续保留。

新增[实际 Application 视口取整修复](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_VIEWPORT_ROUNDING_OCT27.md)。只观察第 2,264 帧的原始 C++ 绘制输入与初始 GPU 颜色，独立 D3D9 固定管线重放 416 次绘制、七次清除：第 192 次绘制出现首差，第 230 次引入原先 `(361,211)` 首个争议像素，源片段／UV 控制确认混合之前已有偏差。生产 WebGPU／GLES 着色器改为加上完整屏幕视口平移后再按 1/256 像素取整。当前 WebGPU 与独立 D3D9 对照的 15 个通道字节差消失，实际 C++ Application 完整 1,228,800 字节也相同；当前实际 C++／Asyncify／JS WebGPU Stage 回归 21／21、25,804,800 字节相同。独立参考使用被观察的初始 GPU 颜色，不等于原版普通 Application 整帧捕获。

当前 GLES 同一实际画面仍有 8 像素、10 个通道字节差，原先三面 1199 帧 `(144,373)` 蓝字节 119／120 也保留。所有四通道完整比较，不排除 alpha 或使用容差。旧 8216 静音候选仍是此前 Bgrx8 完整构建，未把新修复或离屏验收继承给旧候选；普通浏览器及 IndexedDB 尚未验收。

当前修复后两条生产路径各完成三次自然演示／返回标题，均为 17,545 帧、30 项断言、13 项动作，但完整回归失败。七份画面六份相同，第一份演示就绪画面保留上述十字节差；第二次演示约 Application 11,210 帧后出现所见分数差，WebGPU／GLES 日志分别为 4,243／4,239 行，各 12,681,216 帧实际静音 PCM 的累计哈希也不同。原因尚未证明；动作终态相同不代表中间状态相同。新比较器先写入完整负向诊断，再维持图像／日志／PCM 相等门槛并失败退出，见[当前范围报告](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/th14-viewport-rounding-verified-oct27.json)。没有通过选择重复运行移除反例。

此前[完整咲夜 B Hard Application 回放](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_FULL_APPLICATION_REPLAY_OCT26.md)各 123,412 帧、44 项断言、六面激活与自然结束保留冻结版本范围；旧八份图像、日志和 PCM 在更新后的比较工具上正向回归通过，未重跑旧整局。较早[Application 普通归一化输入组件](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_NATIVE_APPLICATION_OCT26.md)的选机、暂停、保存及新进程读回共 239 项断言，以及[续关流程](https://github.com/AdingApkgg/thp/blob/b743b0f360c275c33b84b82956c8dddb911c43eb/docs/porting/TH14_LAUNCHER_CONTINUE_OCT26.md)各 3,637 帧、58 项断言，均不自动继承到当前完整流程。
