## [th14] 東方輝針城 v1.00b

### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植继续。[当前源码与复核工具](https://github.com/AdingApkgg/thp/commit/30d962c12b2a76a1f0e28f579625f02d4052fb8a)；[剩余验收清单](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。只推进 TH14，不新增其他作品占位，整作 1:1 尚未完成。

[30 组模式清单](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_MODE_ACCEPTANCE_OCT25.md)均有原版自然结束记录，25 组观察到全部目标关卡入口。自然结束、全部入口与通关分别判断；魔理沙 A Easy／Normal／Hard、魔理沙 B Normal／Lunatic 五组仍缺后续入口。新增[魔理沙 B Easy](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_MARISAB_EASY_OCT26.md)完整 107,233 回调和[咲夜 A Easy](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_SAKUYAA_EASY_OCT26.md)完整 128,425 回调通过所列严格有限门槛。旧相机、effect149 等失败记录仍保留。

当前[WebGPU Bgrx8 清除／绘制](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_BGRX_RASTER_OCT27.md)在独立 D3D9 HAL／实际 D3DX 转换的 1,344 例中，两条实际 C++ 后端各 4,032 份、4,128,768 字节完整规范化缓冲一致，原始 X8 高字节另存，未丢弃通道。21 Stage、8 D3DX 和 96 stencil 回归通过。此前[矩形 stencil 清除](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/TH14_STENCIL_CLEAR_OCT26.md)的 384 份缓冲也保留各自版本范围。16 位打包光栅与此前混合格式复制继续开放。

真实 SDL3／Asyncify 静音候选已以已发布 Bgrx8 修复为基线重新编译全部 146 个 C++ 单元，Wasm 2,700,129 字节；约 415 MB 生成字体／FLAC 以 28 个不可变别名复用。父 Launcher 的 133 条路由、21 项 HTTP／协议检查，以及实际服务下载的当前宿主／完整 Wasm 字节核对通过，见[候选报告](https://github.com/AdingApkgg/thp/blob/30d962c12b2a76a1f0e28f579625f02d4052fb8a/docs/porting/th14-bgrx-candidate-verified-oct27.json)。普通浏览器、IndexedDB、系统呈现和物理设备尚未验收；默认 WebGL 保留原版本及已知单像素差异，原生 BGRA PNG 导出控制的通道差异也未关闭。
