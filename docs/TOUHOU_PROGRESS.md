### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植继续。[源码与复核工具](https://github.com/AdingApkgg/thp/commit/2c52d7dad38108169abde5c6cb24e94233f81e1d)；[剩余验收](https://github.com/AdingApkgg/thp/blob/2c52d7dad38108169abde5c6cb24e94233f81e1d/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。只推进 TH14，整作 1:1 未完成。

最新[实际原版标题整帧](https://github.com/AdingApkgg/thp/blob/2c52d7dad38108169abde5c6cb24e94233f81e1d/docs/porting/TH14_NATIVE_TITLE_FRAMES_OCT27.md)：移除额外 FPS，并修正首次标题激活提前增加空闲计数。原版空闲计数 51／231 的实际 D3D9 后缓冲，分别与 C++ GLES 的完整 1,228,800 字节相同，231 完整菜单在 WebGPU 下也相同；此前 203／27,980 像素差异归零，容差为零、包含 alpha。回读明确声明私有诊断代码、两次渲染线程重定向、额外 D3D 调用及清理；原有指令、游戏字段、RNG 和输入未写入，不称为未插桩原作或普通界面验收。18 组回读 ABI、16 组 FPS 守卫、36 组标题计数原指令控制通过。[范围摘要](https://github.com/AdingApkgg/thp/blob/2c52d7dad38108169abde5c6cb24e94233f81e1d/docs/porting/th14-native-title-verified-oct27.json)绑定原始捕获与构建。

标题严格 VM 比较仍有 62 项句柄／图层差异。按唯一文件／脚本配对并显式映射链接句柄仅用于定位，不作为严格通过。受计数修改影响，两后端各重跑首次演示前缀 2,265 帧／七项断言，131 行状态、文件与 1,508,352 帧静音 PCM sink 相同，但演示图像 `(32,166)` 的 R／A 两字节不同，失败保留，尚无此次实际绘制的原版裁决。不继承旧版完整演示回归，也未把失败归因给本次修复。
