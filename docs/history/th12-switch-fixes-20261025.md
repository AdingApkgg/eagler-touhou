# TH12 Switch 修复适配

TH12 普通版与多人版同步接入 [saekaze/th12-switch](https://github.com/saekaze/th12-switch) 的修复思路，网页端保留独立资源加载、绘制和多人会话协议。

## 记录与动画

HI SCORE 从当前机体、难度的已保存成绩初始化；Practice 使用对应关卡记录。运行中通过整数分数接口更新最高分，分数末位由续关计数单独组成，未续关时为0。ANM93/94 从当前滚动速度建立插值，零时长指令直接写入速度轴。

来源：[cbad74c](https://github.com/saekaze/th12-switch/commit/cbad74c)。

## 跨关与录像

结算期间预读下一关脚本、背景、贴图与音乐，当前关卡继续执行原生120帧结算及30帧淡出。资源在切关边界安装，普通游戏和顺序播放录像跨关保持游戏画面，不启动加载遮罩。预读不调用关卡选择、核心资源安装或逻辑步进，关卡初始资源与 RNG 按原有关卡头恢复。

现有网页播放入口已启用完整关卡流程，本次通过专用接口明确初始化录像流程和后续关卡淡入；Practice 维持自己的结束规则。多人录像跨关使用记录视角的机体和难度，剧情仍按零号席机体选择。

来源：[4d2e7ada](https://github.com/saekaze/th12-switch/commit/4d2e7ada40ea3364a95f23fe1f83837b6a35bec2)。

## 绘制查找

弹幕绘制查找表使用可复用的连续数组，保持原有动画注册链、外观分组和实体槽位顺序。同一 owner 的后写入记录通过稳定排序和上界查找选择，延续原有字典赋值语义。该表只参与绘制，不写入模拟状态。

来源：[6ca3bd12](https://github.com/saekaze/th12-switch/commit/6ca3bd12203b6fa9f960591de66c5fbfa68ce914)。

## 验证

普通与多人浏览器正式构建均完成。针对性 JavaScript 回归覆盖保存成绩、整数分数及续关末位、ANM 插值、资源预读隔离、直播和录像跨关、多人录像机体与剧情归属。普通版原生阶段测试覆盖跨关资源、RNG、录像结算和淡入、Continue 及原版 MSG。多人浏览器验证两人和三人同步、回滚/非回滚路径、预加载复用、旁观回放与录像重建。

验证记录位于本地 `artifacts/th12-switch-fixes-20261025/`。原有 `game-profile.test.mjs` 的三项断言在两侧 HEAD 基线上同样失败，基线和本轮日志分别保存；本轮针对性回归单独记录结果。
