## [th14] 東方輝針城 v1.00b

### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植继续。[源码与复核工具](https://github.com/AdingApkgg/thp/commit/6ac61159f627700c64c9a79fdef4b7530d399ad4)；[剩余验收](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。只推进 TH14，不新增其他作品占位，整作 1:1 尚未完成。

最新[进程输入控制与 GLES 四边形修复](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_PROCESS_INPUT_QUAD_OCT27.md)：补齐非实例化四顶点 Strip 的已有投影取整判断。先用实际 C++ Renderer 的 192 个语义批次精确复现旧 Application 画面，首差定位到第 149 次绘制／目标 9／BGRA8 纹理 99，绘制前完整缓冲相同。独立 D3D9 的实际 ProcessVertices、浮点源片段与 UV 控制支持定位；私有单项实验后改正式代码，全部 199 次语义绘制／清除后的完整缓冲哈希与 D3D9 相同。当前实际 Application 第 2,264 帧的 GLES 8 像素／10 字节差消失，完整 1,228,800 字节一致。独立参考使用被观察的初始 GPU 颜色，尚不是原版普通 Application 整帧捕获。

两后端重新构建，在声明相同外部进程熵输入后各完成三次演示与返回标题：17,545 帧、30 项断言、13 项动作、4,239 行日志、七幅共 8,601,600 字节完整画面一致，各 12,681,216 帧静音 PCM sink 的累计哈希一致。[范围报告](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/th14-process-input-quad-verified-oct27.json)绑定当前构建和留存数据。实际 C++ 的 cookie 默认逻辑、游戏 RNG、时钟和演示没有改写；冻结单元宿主只声明构造器唯一一次四字节 WASI 熵输入。同一旧 GLES 二进制的两个不同输入控制各 11,220 帧，确实产生不同状态／音效，但旧未记录 cookie 的失败仍未唯一归因。修复前十字节差、旧日志／PCM 失败、最终存储失败的共同输入前缀均保留。

Stage 回归仍为 20／21，三面 1199 帧 `(144,373)` B=119／120 的严格失败继续，见[裁剪与视口偏移次序](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_BACKGROUND_CLIP_ORDER_OCT26.md)。此前[完整视口取整修复](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_VIEWPORT_ROUNDING_OCT27.md)使 WebGPU 在上述实际帧与 D3D9 相同；实际 C++／Asyncify／JS WebGPU Stage 的 21／21 有限结果保留版本范围。所有四通道完整比较，没有容差或 alpha 排除。16 位打包光栅、混合格式复制、BGRA PNG 导出通道及普通浏览器仍开放；[Bgrx8](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_BGRX_RASTER_OCT27.md)和 stencil 等旧组件结果不自动继承到新整局。旧 8216 静音候选尚未更新到当前修复。

[模式清单](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_MODE_ACCEPTANCE_OCT25.md)仍为 30 组自然结束记录、25 组观察到全部目标关卡入口；魔理沙 A Easy／Normal／Hard、魔理沙 B Normal／Lunatic 五组缺后续入口。自然结束与通关分别判断。历史相机／[实际复制观察](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_CAMERA_WORD_STAGE4_OCT27.md)、[effect149 栈来源](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_FOCUSED_HIT_STACK_PRODUCER_OCT26.md)、原版普通流程／画面及浏览器持久化／输入／音频继续验收。此前[完整咲夜 B Hard Application](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_FULL_APPLICATION_REPLAY_OCT26.md)的 123,412 帧及[续关流程](https://github.com/AdingApkgg/thp/blob/6ac61159f627700c64c9a79fdef4b7530d399ad4/docs/porting/TH14_LAUNCHER_CONTINUE_OCT26.md)等仍是冻结版本的有限范围结果。
