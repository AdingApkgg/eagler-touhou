### th14 还原、移植与 Web 适配

独立 C++／Wasm 移植与 Web 适配继续进行。[当前源码与复核工具](https://github.com/AdingApkgg/thp/commit/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd)；[剩余验收清单](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_REMAINING_ACCEPTANCE.md)。仅推进 TH14，不新增其他作品占位，尚未标记整作 1:1 完成。

[30 组模式清单](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_MODE_ACCEPTANCE_OCT25.md)现均有原版自然结束记录，25 组观察到全部目标关卡入口，分别判断自然结束、入口与通关。新增[魔理沙 B Easy](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_MARISAB_EASY_OCT26.md)完整 107,233 回调和[咲夜 A Easy](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_SAKUYAA_EASY_OCT26.md)完整 128,425 回调通过所列状态、相机、HUD、动画及采样战斗对象的严格有限复算。现有魔理沙 A Easy／Normal／Hard、魔理沙 B Normal／Lunatic 仍缺后续关卡入口，不把自然结束写成全部通关。

新增[JavaScript WebGPU 主机与 Asyncify 接入](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_JS_WEBGPU_OCT26.md)。实际 C++ → Emscripten／Asyncify → JavaScript WebGPU 链在原生 Deno 设备接口上通过 21／21 个 Stage 原版完整缓冲、25,804,800 字节，以及 8／8 个 D3DX 捕获完整缓冲、5,242,880 字节比较。读回暂停期间内存增长 65,536 字节，2,048 个 C++ 栈保护字、加载／帧回调与排队输入共六次调用通过，重复启动绑定保持幂等。实际 Application 当前回归继续通过 239 项断言及 18 幅成对画面、PCM 和文件检查。

真实 SDL3 浏览器候选已由 146 个 C++ 编译单元构建，Wasm 2,699,895 字节；初始化、GPU 读回、加载／帧回调、输入及 shell 已接入异步队列。生成字体／FLAC 的 414,850,582 字节通过已验证缓存别名复用。普通 Chrome、系统呈现与浏览器持久化尚未验收，默认 WebGL 预览保持原版本及单像素差异。原生 Canvas 两种格式的 GPU 原字节正确，BGRA PNG 导出控制仍出现红蓝互换，RGBA 控制正确；失败单独保留。此前[C++／原生 GPU 接入](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_CPP_WEBGPU_OCT26.md)保留原始范围，不把编译、原生 API 或成对 Application 画面当作浏览器／原版普通菜单验收。

[effect149 栈来源](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_FOCUSED_HIT_STACK_PRODUCER_OCT26.md)的 960 组公共命中链原指令组件确认，奖励函数保存的目标坐标指针被下一回调作为 Z 读回，另有 15 个跳过消费者的控制。11 个整局差异字关联到保留过的敌机位置地址，但仅三个是同一回调证据；较早地址复用、生产 ABI／地址模型和调用点仍待核对，原始 Z 字差继续失败。[咲夜 B Easy 相机交错](https://github.com/AdingApkgg/thp/blob/3a52b428a603a35c3e4a6bd0cabf3a6536bb67fd/docs/porting/TH14_SAKUYAB_EASY_CAMERA_FAILURE_OCT26.md)及其他历史失败也保留。
