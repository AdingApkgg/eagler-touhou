# 绀珠传全关卡性能优化与验收（2026-10-04）

本轮范围为一至六面、Extra，以及标题、Music Room、Player Data、Replay、Options、Manual、Practice、暂停和返回标题。保留原版逻辑和已有五面优化，渲染继续使用共用 C++ SDL3 / WebGL2 后端。

修改：

- 同步 LZSS 解压使用按字段读取的位缓存，保留字典、零填充 EOF、重叠引用和截断检查；异步解压和录像编码不改动。全原版资源和原版编解码对照验证。
- 孤立的长 Strip/Fan 直接上传原有顶点；若后续兼容绘制需要合批，按原版三角形顺序展开并加入。保留透明绘制顺序、绕序、既有布局缓存和 glBufferData 更新策略。
- 长曲线激光直接交给共用渲染器，减少先展开进游戏精灵缓冲再处理的重复工作。短激光保留原精灵合批路径。
- 原版 th15.dat 直接读入归档缓冲，避免 SDL_LoadFile 后再次复制完整 77,453,661 字节归档。此为瞬时分配减少，不能据此推断最终 Wasm 堆大小下降。
- Manual PNG 对 BGRA8 / ARGB4444 目标直接生成最终纹理，保留原版裁剪、透明补齐和通道量化。九张原版页面独立像素金样验证。

共享渲染器的 copiedBytes 只计算该层复制，不包含游戏精灵缓冲的写入。长激光转交该层后部分计数上升，这是复制分类和合批归一化的变化；不能单独使用该计数判断全帧 CPU 复制开销。最终 Wasm 堆大小也并非每关都下降。
