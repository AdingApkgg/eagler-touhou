# 整局状态与实际网页验收

整款 C++ 实现及本地发布验收已通过，target.json 的 completeGame=true。该字段表示整款实现和发布流程已经接通，不是所有可能操作零差异/零缺陷的数学证明。公网手机模拟游玩验证已通过，服务为 3007。

## 本轮实际发现并修复的问题

- 同一帧首次命中后及时更新自机决死状态，避免后续圆形、矩形和激光判定重复受击及额外视觉随机数。
- Bomb 读取实际敌人数及对话保护；铃仙的判定尺寸读取实时值。
- 敌人中断、ECL、自机与符卡管理器共享同一份 PlayerSpellStatus，避免覆盖超时和生存符卡标记。
- 按原版优先级 15 推进 GameHud::update_score，修复内部得分增长而显示分数、高分始终为零。
- 暂停 Retry 设置新局标记并恢复起始关卡，修复从二面重试时对象未初始化。
- 四面初始背景动画尚未选择精灵时，按原版银行/索引读取尺寸，且仅在 STD 尺寸非零时读取，修复跨关报错。
- 原版目的地 15 创建结局，16 创建标题/结算；修复普通结局结束后再次创建结局及 Extra 错误进入结局。
- 资源包只包含正常字体 0–7，备用字体仍在开发资产中；不可变资源采用 MEMFS canOwn，移除一份资源包内存复制。
